# Landing assets

Replaceable brand and product media belong here. When the final identity is available, use clear
files for the horizontal logo, symbol, negative logo, admin dashboard, storefront and product
detail captures. Keep screenshots as regular responsive images instead of CSS backgrounds so they
can be updated without changing the layout.

The current landing intentionally uses a neutral text mark and a code-based preview; it does not
contain a provisional logo or fabricated product screenshots.

## Commercial contact

The demo-request CTA is intentionally disabled until Comercio Flex has a verified company-owned
channel. Set `contactHref` once in `landing.config.ts` to a real `mailto:` or HTTPS
WhatsApp/contact URL before enabling that CTA. Do not duplicate contact data in components.
